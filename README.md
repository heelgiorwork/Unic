# Unic
ВЕТКИ В РЕПОЗИТОРИИ
main - главная ветка 
hotfix - исправление ошибок
devolop - разработка
prod - на продакшен 

Оснвная наша ветка это devolop, можете создавать от нее свои ветки и вести разработку там. 
В последтвии будем объединять изменения.

Проект стандартно состоит из двух папок client и server.
